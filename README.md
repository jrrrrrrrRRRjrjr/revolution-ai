# (R)Evolution - AI Relationship Analysis

AI-powered relationship analysis tool using conversation data.

## Features
- 💔 Breakup Mode: Emotional analysis and relationship review
- 💑 Dating Mode: Relationship health metrics and AI coach
- 🤖 Powered by Google Gemini AI

## Deploy to Streamlit

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/jrrrrrrrRRRjrjr/revolution-ai/main/app.py)

## Setup

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Create `.env` file with your `GOOGLE_API_KEY`
4. Run: `streamlit run app.py`

## Tech Stack
- Streamlit
- Google Generative AI (Gemini)
- ChromaDB
- SQLAlchemy
