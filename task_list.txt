Jo님, 저를 믿어주셔서 감사합니다. '간단히'라는 의미가 "MVP 외의 기능은 제외"라는 뜻이었군요. 완벽하게 이해했습니다.

Jo님은 이 프로젝트의 기획자(PO)이자 핵심 개발자이십니다. 저는 Jo님의 파트너 AI로서, 이 기획을 현실로 만들기 위한 **세세하고 꼼꼼한 개발 태스크 목록**을 만들었습니다. Jo님의 Python 지식을 바탕으로 이 순서대로 하나씩 체크해 나가시면 됩니다.

### 📱 (R)Evolution 개발 태스크 목록 (MVP v1.0)

#### 1단계: 프로젝트 환경 설정 (Foundation)

- [ ] `(R)Evolution` 프로젝트 폴더 생성
- [ ] Python 가상 환경 설정 (`venv`)
- [ ] Git 저장소 초기화 (`git init`)
- [ ] `.gitignore` 파일 생성 (API 키, 데이터 파일 등 민감 정보 제외)
- [ ] `requirements.txt` 파일 생성
- [ ] 핵심 Python 라이브러리 설치
    - [ ] `pip install streamlit` (UI/UX 화면 구성)
    - [ ] `pip install langchain` (AI 파이프라인 '접착제')
    - [ ] `pip install openai` (AI의 '두뇌' API)
    - [ ] `pip install chromadb` (AI의 '기억 저장소' - 벡터 DB)
    - [ ] `pip install sqlalchemy` (사용자 정보 '파일 캐비닛' - 관계형 DB)
- [ ] OpenAI (또는 Google AI) API 키 발급 및 환경 변수 설정

---

#### 2단계: 데이터베이스 설계 (The Schema)

- [ ] **'사용자 정보 DB' (SQLite/SQLAlchemy) 스키마 작성**
    - [ ] `Users` (사용자 계정) 테이블 모델 정의
    - [ ] `Relationships` (관계 목록 - "연애 중", "이별" 상태 포함) 테이블 모델 정의
    - [ ] `Participants` (참여자 정보 - MBTI, 나이, 성별) 테이블 모델 정의
    - [ ] `Hobbies` (AI 코치 권유용) 테이블 모델 정의
- [ ] **'AI 기억 DB' (ChromaDB) Collection 구조 설계**
    - [ ] 대화록 저장을 위한 Collection 생성 로직
    - [ ] '근거 제시'를 위한 메타데이터 구조 정의 (예: `speaker`, `timestamp`, `topic_keywords`)

---

#### 3단계: UI/UX 프론트엔드 (Streamlit)

- [ ] **메인 `app.py` 파일 생성**
- [ ] **[스크린 1] 홈 화면 (모드 선택)**
    - [ ] "(R)Evolution" 타이틀 표시
    - [ ] "연애 중" 버튼 UI 생성
    - [ ] "이별" 버튼 UI 생성
    - [ ] `st.session_state`를 이용한 모드 전환 로직 구현
- [ ] **[스크린 2] 온보딩 (정보 입력)**
    - [ ] 나이, 성별, MBTI 입력 필드 (본인/상대방)
    - [ ] 관계 기간, LDR 여부 입력 필드
    - [ ] `.txt` 파일 업로드 위젯 (`st.file_uploader`) 구현
    - [ ] 입력 정보를 '사용자 정보 DB'(SQLite)에 저장하는 로직 구현
    - [ ] 업로드된 대화록을 'AI 기억 DB'(ChromaDB)에 저장하는 로직 구현
